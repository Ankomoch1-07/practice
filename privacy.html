ホームプライバシーポリシー

プライバシーポリシー

whatif-shorts-uploader（運営：Increatism Inc.） ・ 制定日：2026年10月18日

1. 対象

このポリシーは、Increatism Inc.（以下「運営者」）が運用する社内用ツール whatif-shorts-uploader（以下「本ツール」）における、Google アカウントの情報の取り扱いを定めるものです。本ツールは運営者が自社の YouTube チャンネルで使うためのもので、一般の利用者には提供していません。

2. 取得する情報

  • 運営者自身の Google アカウントについて、Google の OAuth 2.0 で発行される認証トークン（アクセストークン・リフレッシュトークン）
  • 許可を受ける範囲：youtube.upload（動画のアップロード）、youtube.readonly（アップロード先チャンネル名の確認）

運営者以外の個人情報、視聴者の情報、コメント、連絡先などは取得しません。

3. 利用目的

取得したトークンは、運営者が制作した動画を運営者自身の YouTube チャンネルに非公開でアップロードし、アップロード先のチャンネルを確認するためだけに使います。広告、分析、第三者への提供、販売には使いません。

4. 保管と共有

  • トークンは、運営者が管理するクラウド実行環境の非公開の環境変数にのみ保管し、ソースコードや公開リポジトリには保存しません。
  • 法令に基づく場合を除き、第三者に提供・開示しません。

5. Google API サービスのユーザーデータに関するポリシーの遵守

本ツールが Google API から受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（限定使用の要件を含む）に従います。

6. 許可の取り消しと削除

本ツールへの許可は、Google アカウントのサードパーティ アクセス設定からいつでも取り消せます。取り消し後、保管していたトークンは無効になり、運営者は実行環境から削除します。

7. お問い合わせ

本ポリシーに関するお問い合わせは、こちらのページからお送りください。

English

whatif-shorts-uploader is an internal tool operated by Increatism Inc. It obtains OAuth tokens only for the operator's own Google account, with the scopes youtube.upload and youtube.readonly, solely to upload videos produced by the operator to the operator's own YouTube channel as private videos and to confirm the destination channel. No data of any other user is collected. Tokens are stored only in private environment variables of the operator's cloud environment and are never sold, shared, or used for advertising. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
